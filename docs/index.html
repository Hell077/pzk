03 / CONTEXT BEFORE ACTION

A little caution.
A lot less disruption.

Read the safety model ↗
01

Inspect freely.

Browsing and monitoring are read-only. No firewall changes, automatic restarts, or hidden background agent.

02

Confirm the whole impact.

Stopping a port owner affects its other ports, too. Review all visible owners before typing yes. Force always requires an explicit flag.

03

Check the identity again.

Ownership is rechecked before shutdown. Linux and Windows use process-bound handles. macOS revalidates start time; a small OS-level race remains.
